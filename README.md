# Tarea2-Robotica
Implementación del Laboratorio 2 de Robótica y Sistemas Autónomos en Webots. El proyecto desarrolla un controlador para el robot e-puck con navegación reactiva, lectura de sensores de proximidad y encoders, filtrado por media móvil, fusión sensorial mediante filtro de Kalman y registro de datos en CSV para análisis de señales.
